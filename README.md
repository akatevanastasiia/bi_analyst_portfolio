# Портфолио | Акатьева Анастасия | BI-аналитик

## Как прогнать пример

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python analyze_call.py
```

В `.env` нужны свой `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. 

Подробности по версиям промптов: [prompts/README.md](prompts/README.md).
